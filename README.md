# Cortex Rush

Crash-игра для телефона про жизнь компонента в дизайн-системе Cortex. Ядро компонента идёт по конвейеру «бриф → гейт A → проектирование → гейт B → Jira → страница → гейт C → публикация», множитель растёт с каждым этапом. Задача — нажать «Опубликовать» до детача.

Токены в игре виртуальные: их нельзя купить или вывести.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | Вся игра: разметка, стили на токенах Cortex, логика и рендер |
| `manifest.webmanifest` | Описание PWA: название, иконки, портретный режим |
| `sw.js` | Офлайн-кэш: после первого открытия игра запускается без сети |
| `icons/` | Иконки приложения и фавикон |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |

Сборка не нужна: это статический сайт без зависимостей. Шрифты Inter и JetBrains Mono грузятся с Google Fonts, без сети используются системные.

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub, например `cortex-rush`.
2. Загрузи в корень все файлы из этой папки, включая `.nojekyll` (через «Add file → Upload files» или `git push`).
3. Открой **Settings → Pages**, в разделе **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажми **Save**.
4. Через минуту-две игра будет доступна по адресу `https://<твой-логин>.github.io/cortex-rush/`.

Через командную строку:

```bash
git init
git add .
git commit -m "Cortex Rush: первая версия"
git branch -M main
git remote add origin https://github.com/<твой-логин>/cortex-rush.git
git push -u origin main
```

Если репозиторий приватный, GitHub Pages доступен не на всех тарифах — проверь в настройках репозитория.

## Установка на телефон

- **Android, Chrome:** меню ⋮ → «Установить приложение» или «Добавить на главный экран».
- **iPhone, Safari:** «Поделиться» → «На экран „Домой“».

## Как выпускать обновления

1. Внеси изменения в `index.html`.
2. Увеличь версию кэша в `sw.js`: `cortex-rush-v1` → `cortex-rush-v2`.
3. Закоммить и запушь. У игроков новая версия подтянется при следующем открытии.

## Честность раундов

Результат каждого раунда считается заранее из цепочки ключей (SHA-256) и HMAC-SHA256, RTP 97%. В меню «Раунды и проверка честности» любой раунд можно пересчитать в браузере. В прототипе «сервер» работает прямо на устройстве, поэтому для настоящих денег эта схема не подходит — она нужна, чтобы показать механику.
